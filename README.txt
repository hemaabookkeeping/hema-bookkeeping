# Hema Ayadassen — Professional Bookkeeping Website

Open `index.html` in a browser to preview the site.

## Publish free with GitHub Pages
1. Create a GitHub account at github.com.
2. Create a new public repository, for example `hema-bookkeeping`.
3. Upload `index.html`.
4. In the repository, open Settings → Pages.
5. Choose deployment from the main branch and save.
6. GitHub will provide your free `github.io` website address.

No testimonials or people/photos are used. The site includes bookkeeping services, payroll services, your credentials, Northampton, email contact, and the affordable/transparent pricing wording.
